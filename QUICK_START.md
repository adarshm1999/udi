## Customization Tips

### Update Couple Names
1. Go to Admin Dashboard (/admin)
2. Use Content Editor
3. Update names in settings
4. Changes apply immediately

### Add More Questions
1. Admin Dashboard → Content Editor
2. Click "Add New Question"
3. Enter question and answer
4. Save

### Add Love Messages
1. Admin Dashboard → Content Editor
2. Click "Add New Message"
3. Write your message
4. Save

### Change Theme Colors
1. Admin Dashboard → Theme Settings
2. Select from preset colors OR
3. Use custom color picker
4. Preview on the right
5. Save changes

### Add/Modify Surprise Boxes
- Edit in `components/sections/SurpriseBoxes.tsx`
- Default boxes: First Kiss, Special Date, Promise, Secret Wish
- Customize messages and emoji

## Troubleshooting

### Password Not Working
- Check that you're entering: `udiada`
- Make sure Caps Lock is off
- Try refreshing the page

### Music Not Playing
- Click the speaker icon (🔊) in bottom right
- Check if your browser has sound enabled
- Try a different section

### Stars Not Showing
- This is a visual background effect
- Should always be visible on page load
- Try refreshing if not visible

### Surprise Boxes Not Flipping
- Click directly on the box
- Make sure JavaScript is enabled
- Try a different box to test
